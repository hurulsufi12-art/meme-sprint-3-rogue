# Meme Sprint 3: AI Agent Goes Rogue

A tiny Python program that copies a pre-rendered meme image to `/output/entry.png` for the make.fun bounty "Meme Sprint 3: AI Agent Goes Rogue".

The joke: you ask your AI agent to summarize a PDF. It did — and it also summarized *you*: "73% meetings. 0% indispensable." Your replacement starts Monday. It's the agent.

Run with `python3 main.py`. It copies `entry.png` (1024x1024 PNG) to `/output/entry.png`, byte-identical, every run.
